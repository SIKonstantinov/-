# Крипто-дайджест в Telegram

Бот раз в день собирает свежие новости о криптовалютах из RSS-лент и присылает их одним сообщением в Telegram.
Работает бесплатно на GitHub Actions — свой сервер не нужен.

## Настройка (один раз, ~5 минут)

1. **Создай бота.** В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot`, придумай имя.
   BotFather пришлёт токен вида `123456:ABC-DEF...`.
2. **Напиши своему боту** любое сообщение (например, `/start`) — иначе он не сможет писать тебе первым.
3. **Узнай свой chat_id.** Открой в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id": 123456789 ...}`.
   Или локально: `TELEGRAM_BOT_TOKEN=<ТОКЕН> python -m bot --chat-id`.
4. **Добавь секреты в репозиторий:** GitHub → *Settings → Secrets and variables → Actions → New repository secret*:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1;
   - `TELEGRAM_CHAT_ID` — число из шага 3.
5. **Проверь:** вкладка *Actions → Crypto digest → Run workflow*. Через минуту дайджест придёт в Telegram.

Дальше бот будет присылать дайджест каждый день около **9:00 по Москве**.

## Как поменять

| Что | Где |
|---|---|
| Время отправки | `.github/workflows/digest.yml`, строка `cron` (время в **UTC**: МСК − 3 часа) |
| Источники новостей | `feeds.txt` — одна RSS-лента на строку |
| Сколько новостей с источника | переменная `MAX_PER_SOURCE` (по умолчанию 5) |
| За какой период | переменная `LOOKBACK_HOURS` (по умолчанию 24) |
| Часовой пояс в сообщении | переменная `TIMEZONE` (по умолчанию `Europe/Moscow`) |

Переменные задаются в блоке `env:` шага `python -m bot` в `digest.yml`.

## Локальный запуск

```bash
pip install -r requirements-dev.txt
python -m bot --dry-run   # напечатать дайджест, ничего не отправляя
pytest                    # тесты
```

## Нюансы GitHub Actions

- Расписание срабатывает только в **ветке по умолчанию** репозитория.
- GitHub может запускать cron с задержкой от нескольких минут до получаса в часы пик.
- В публичных репозиториях расписание отключается после 60 дней без коммитов —
  GitHub пришлёт письмо, включить обратно можно одной кнопкой во вкладке *Actions*.
